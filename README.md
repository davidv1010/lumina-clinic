# Lumina Clinic — Estética Avançada

Site de uma clínica de estética fictícia em Betim - MG, feito com HTML, CSS e JavaScript puros.

Projeto acadêmico desenvolvido para a disciplina de Biomedicina Estética da PUC Minas - Campus Betim, sob orientação da professora Karina Rodovanski.

## Estrutura

- `index.html`: página única com todas as seções
- `css/style.css`: estilos (mobile-first)
- `js/main.js`: menu, carrossel de depoimentos, perguntas frequentes e formulário que abre o WhatsApp
- `fotos/`: imagens otimizadas em WebP e ilustrações dos procedimentos em SVG

## Como abrir

Abra o `index.html` no navegador. Não precisa de instalação.
